# Image Tutorial Fixtures

These local encoded images make the contact-sheet tutorial reproducible without
network downloads:

- [mountains.jpg](mountains.jpg) provides a photographic landscape for fitting and cropping.
- [flower.png](flower.png) supplies a second image for crop and placement comparisons.
- [pattern.webp](pattern.webp) demonstrates a different encoded image format.
- [pixel-art.png](pixel-art.png) makes nearest-neighbor enlargement easy to inspect.

The complete consumer is [../contact-sheet.rkt](../contact-sheet.rkt).
[../eval.rkt](../eval.rkt) resolves the same directory for executable manual examples.
