# Quick Tutorial

[quick.scrbl](quick.scrbl) is the illustrated introduction to drawing with
Skia. Its complete landscape program is [moonlight.rkt](moonlight.rkt);
[eval.rkt](eval.rkt) evaluates the manual's incremental examples in a shared
sandbox so the displayed code and figures stay connected.

Quick is registered as a tutorial even though its sources live outside the
main [tutorials/](../tutorials/README.md) directory. See the manual for running
and exporting the example; running the program may create image or document files.
